# F-Droid repo: WiseGuy and Reveries

This folder holds an F-Droid repository for the WiseGuy and Reveries apps,
served by GitHub Pages at https://eldridge-frost.github.io/reveries/fdroid/repo

Add that address in the F-Droid app to install both apps. The repo is signed
with its own key; the APKs keep their original developer signatures, so
installing over the current builds preserves chats and memories (except users
still on the ORIGINAL Reveries build before v10.261 — they must export a
backup first, uninstall, install, then import).

Do NOT publish or announce this address until Jack confirms the installs on
his phone.
